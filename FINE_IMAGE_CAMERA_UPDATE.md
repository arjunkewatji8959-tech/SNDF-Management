# SNDF Fine Image + Officer Update

- Every Fine section now includes a live camera and captured evidence image.
- Fine can be submitted using a Staff ID manually or from the datalist.
- Fine image is stored in the `fines.image` field.
- Admin and Master Admin can create an Officer.
- Officer has a dedicated dashboard with self attendance, notices, account and profile.
- Officer receives a dedicated reliever notification when assigned as a reliever.
- Existing production database remains external to this ZIP; do not overwrite `data/sndf.db`.
