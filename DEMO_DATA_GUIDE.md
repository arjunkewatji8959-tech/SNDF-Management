# SNDF Management Demo Data

This package contains a local demo database with:
- 1 Admin: admin / adi2026
- 1 Field Officer: FO001 / field123
- 3 Supervisors: SUP001-SUP003 / super123
- 15 Guards: G001-G015 / guard123
- 3 Locations: LOC-01, LOC-02, LOC-03
- Sample attendance for 1-3 September 2026
- Sample fines, one suspended guard, notices, help requests, advance and payment

To reset the demo database:
npm run seed-demo

Demo passwords are intentionally simple for local testing. Change them before production.
